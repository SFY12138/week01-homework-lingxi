# 灵犀 AI 对话助手

## 项目简介

一个仿 WPS 灵犀风格的 AI 对话助手，接入阿里云百炼大模型 API，实现真实的 AI 对话功能

## 开发任务索引

- [x] 首页设计：欢迎标题、渐变色文字效果、快捷建议卡片
- [x] 对话功能：接入阿里云百炼 API，实现真实的 AI 问答
- [x] 流式响应：实现打字机效果，逐字显示 AI 回复
- [x] Markdown 渲染：支持标题、表格、代码块、列表、引用等
- [x] 主题切换：支持深色/浅色模式，本地存储保存偏好
- [x] 底部输入区：固定位置、发送按钮、图片上传、主题切换、清除对话
- [x] 其他细节：代码块语法高亮和复制功能、键盘快捷键支持
- [x] 图文对话：支持图片上传和分析

## 核心技术实现

### 1. 流式响应实现
- 使用 Fetch API 配合 ReadableStream 处理服务器发送的流式数据
- 逐块解析 SSE 格式的响应数据
- 实时更新 DOM，实现打字机效果
- 支持中途停止生成

### 2. 主题切换系统
- 使用 CSS 变量和类名切换实现主题
- localStorage 存储用户主题偏好
- 页面加载时自动应用保存的主题

### 3. Markdown 渲染
- 正则表达式解析 Markdown 语法
- 转换为对应的 HTML 结构
- 为代码块添加复制功能

### 4. 图文对话功能
- FileReader API 读取图片文件
- 转换为 base64 编码格式
- 使用 qwen-vl-plus 视觉模型分析图片
- 构建符合 API 要求的多模态消息格式

### 5. 性能优化
- DOM 元素缓存，减少重复查询
- 事件委托和事件监听优化
- 使用 transform 和 opacity 进行动画，避免布局重排

### 6. 错误处理
- 完善的 API 错误捕获
- 友好的用户错误提示
- 控制台详细错误日志

## 如何使用

1. **克隆项目**到本地
2. **启动本地服务器**（推荐使用 VS Code 的 Live Server 插件）
3. **打开浏览器**访问 `http://localhost:5500/week01/homework/lingxi/index.html`
4. **首次使用**时，会提示输入阿里云百炼 API Key
5. **开始对话**，可以输入问题或点击快捷建议卡片

## API Key 设置

- API Key 会存储在浏览器的本地存储中，键名为 `LINGXI_API_KEY`
- 请确保使用有效的阿里云百炼 API Key
- 新人一般有免费额度，可在阿里云百炼控制台申请

## 注意事项

- 请不要将 API Key 提交到代码仓库
- 本项目仅用于学习和练习
- 如有问题，请检查浏览器控制台是否有错误信息
